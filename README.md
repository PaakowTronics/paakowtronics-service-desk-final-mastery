# PaakowTronics Service Desk — Git Essentials Final Mastery

This package contains a reproducible practical assessment for learners who have completed the **Git Essentials** course.

The assessment is designed to test Git as a working skill rather than command memorisation. The learner is given a small service-desk repository containing normal work, unrelated work, a questionable change, overlapping changes, and a later recovery problem.

## Course

https://github.com/PaakowTronics/git-essentials

## How the assessment works

The learner receives a fresh `assessment-repository/` generated by the setup script. The learner's instructions are inside that repository.

The instructor should:

1. Read `INSTRUCTOR-SETUP.md`.
2. Run `setup.sh` or `setup.ps1`.
3. Give the learner the generated `assessment-repository/` and `LEARNER-BRIEF.md`.
4. Keep `INSTRUCTOR-ANSWER-KEY.md` private.
5. Introduce the recovery test only when the learner reaches the recovery stage.
6. Use `reset.sh` or `reset.ps1` to prepare a fresh attempt.

```text
├── RESET.md

├── prepare-recovery-test.sh
├── prepare-recovery-test.ps1
├── reset.sh
├── reset.ps1
└── starter-remote.bundle
```

The bundle is the single source of truth for the prepared Git history. The learner repository is generated at setup time, so the assessment package does not need to ship another nested Git repository.

## Assessment philosophy

The learner should repeatedly move through this cycle:

**investigate → understand → plan → act → verify → recover → explain**

The challenge does not normally name the Git command or feature that should be used. The learner must determine the appropriate operation from the situation.
